# Trend sample

Made-up data, to check how the trend chart in `progress/` looks once a
project has some history. Generated by `examples/trend_sample.py` with
`pmtrack.trend()`.

## Eight days

Up to ten days, each label also carries the value.

```mermaid
%%{init: {"themeVariables": {"xyChart": {"plotColorPalette": "#0ca30c"}}, "xyChart": {"height": 320}}}%%
xychart-beta
  title "all: % done by day"
  x-axis ["10-16 · 4%", "10-17 · 9%", "10-18 · 9%", "10-19 · 15%", "10-20 · 22%", "10-21 · 22%", "10-22 · 31%", "10-23 · 38%"]
  y-axis "% done" 0 --> 100
  bar [4, 9, 9, 15, 22, 22, 31, 38]
```
